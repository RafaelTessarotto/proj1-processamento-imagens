# Processador de Imagens SDL3 - Projeto 1 (Computação Visual)

Software de processamento de imagens desenvolvido em C utilizando a biblioteca SDL3, capaz de converter imagens coloridas para escala de cinza, analisar e equalizar histogramas, e manipular a resolução de exibição.

## Processo de Compilação
O projeto foi desenvolvido e unificado em ambiente Linux (Ubuntu/Debian).

* **Sistema Operacional:** WSL Ubuntu 26.04
* **Compilador:** GCC 15.2.0
* **Bibliotecas:** SDL3 (3.4.16), SDL3_image e SDL3_ttf

**Como compilar e executar:**
1. Instale as bibliotecas SDL3, SDL3_image e SDL3_ttf no sistema operacional.
2. Na raiz do projeto, execute o comando `make` para compilar.
3. Execute o programa passando a imagem como argumento: `./programa assets/test_image1.png`
